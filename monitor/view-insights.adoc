= Optimiza la seguridad y el rendimiento del clúster con ASA r2 System Insights
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vea _Insights_ en ONTAP System Manager para identificar las prácticas recomendadas y las modificaciones de configuración que puede implementar en su sistema ASA R2 para optimizar la seguridad y el rendimiento de los clústeres.

Por ejemplo, supongamos que tienes servidores Network Time Protocol (NTP) configurados para tu clúster. Sin embargo, no sabes que tienes menos servidores NTP de los recomendados para una gestión óptima del tiempo del clúster. Para ayudarte a evitar problemas que pueden ocurrir cuando la hora del clúster es inexacta, Insights te avisa de que tienes muy pocos servidores NTP configurados y te da opciones para saber más sobre el problema, solucionarlo o descartarlo.

image:insights.png["captura de pantalla de la página de información del administrador del sistema"]

.Pasos
. En System Manager, selecciona *Insights*.
. Revise las recomendaciones.


.El futuro
Realice las acciones necesarias para implementar las prácticas recomendadas y optimizar la seguridad y el rendimiento del clúster.
