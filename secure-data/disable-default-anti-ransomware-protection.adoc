= Desactivar la protección autónoma contra ransomware predeterminada en los sistemas de almacenamiento ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Al inicializar un nuevo clúster ONTAP 9.18.1 ASA r2 o al actualizar un clúster a ONTAP 9.18.1, ARP/AI se habilita de forma predeterminada en todas las nuevas unidades de almacenamiento tras un periodo de gracia de 12 horas. Si no desactivas ARP/AI durante ese periodo, ONTAP lo habilita en todo el clúster para las nuevas unidades de almacenamiento cuando finaliza el periodo de gracia.

Las unidades de almacenamiento creadas en ONTAP 9.17.1 deben ser link:enable-anti-ransomware-protection.html["activado manualmente"] para ARP/AI.

.Pasos
Puedes desactivar la activación por defecto durante o después del periodo de gracia inicial de 12 horas.

[role="tabbed-block"]
====
.System Manager
--
. Seleccione *Cluster > Settings*.
. Desactiva ARP:
+
** Para desactivar durante el periodo de gracia de 12 horas:
+
... En *Anti-ransomware*, selecciona *No habilitar* y luego selecciona *Desactivar*.


** Para desactivar después del periodo de gracia de 12 horas:
+
... En *Anti-ransomware*, selecciona image:icon_pencil.gif["Editar"] y luego desmarca *Activar para nuevas unidades de almacenamiento*.
... Selecciona *Guardar*






--
.CLI
--
. Verifica el estado de habilitación predeterminado:
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Desactivar la habilitación predeterminada para las unidades de almacenamiento existentes y nuevas:
+
[source, cli]
----
security anti-ransomware auto-enable modify -default-existing-volume-state false -default-new-volume-state false
----
