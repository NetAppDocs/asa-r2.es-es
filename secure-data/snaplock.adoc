= Conoce la protección de datos de SnapLock para los sistemas de almacenamiento ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP SnapLock es una solución de cumplimiento de alto rendimiento para organizaciones que utilizan almacenamiento WORM para conservar archivos sin modificaciones con fines normativos y de gobernanza. Puedes ejecutar SnapLock en los modos Compliance o Enterprise, que ofrecen distintos niveles de protección de datos WORM. Los modos SnapLock Compliance y Enterprise no son compatibles con clústeres primarios en entornos SAN, pero puedes habilitar SnapLock para SnapVault en tus sistemas secundarios para proteger las instantáneas secundarias frente a un borrado accidental o malintencionado.

El SnapLock Compliance Clock debe inicializarse en link:../data-protection/snapshot-replication.html["protege las instantáneas de tus sistemas secundarios con SnapLock para SnapVault"].

A partir de ONTAP 9.20.1, puedes configurar el backend de SnapLock para SnapVault para la replicación a través de fabrics FC existentes. Para ello, el backend de tu sistema ONTAP debe estar configurado para la replicación FC, y tanto el fabric FC como la red IP entre clústeres deben estar operativos. Los datos de replicación pueden transportarse a través del fabric FC, pero la red IP entre clústeres es necesaria para las comunicaciones del clúster y las funciones de gestión de la replicación.

Aprende a link:https://docs.netapp.com/us-en/ontap/data-protection/configure-backend-fc-replication.html["configura el backend de tu sistema ONTAP para la replicación FC"^].

== Inicializa el reloj de cumplimiento de SnapLock Compliance

Si deseas proteger las instantáneas de destino en un sistema secundario con SnapLock para SnapVault, primero debes inicializar el SnapLock Compliance Clock en tus clústeres local y de destino.

.Pasos
. Seleccione *Cluster > Overview*.
. En la sección *Nodos*, selecciona *Inicializar reloj SnapLock Compliance*.
. Selecciona *Inicializar*.
. Comprueba que el Compliance Clock esté inicializado.
+
.. Seleccione *Cluster > Overview*.
.. En la sección *Nodos*, seleccione image:icon_show_hide.png["tres columnas azules sobre fondo blanco"]; y luego seleccione *Reloj SnapLock Compliance*.




.¿Cuál es el siguiente?
Después de que hayas inicializado el SnapLock Compliance Clock en tus clústeres local y de destino, ya estás listo para link:../data-protection/snapshot-replication.html["crea una relación de replicación con SnapLock para SnapVault"].
