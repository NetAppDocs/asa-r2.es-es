= Funciones comunes de ONTAP compatibles con los sistemas ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dado que los sistemas ASA r2 ejecutan una versión optimizada de ONTAP, realizas muchas de las tareas habituales de ONTAP y las funciones de System Manager de la misma forma que en otros sistemas ONTAP.

Para obtener más información sobre las características y funciones comunes, consulte la siguiente documentación de ONTAP .



[[autosupport]]
== AutoSupport

A partir de ONTAP 9.20.1, System Manager muestra alertas de AutoSupport si AutoSupport está configurado para el protocolo SMTP en lugar del protocolo HTTPs, si AutoSupport está desactivado pero los destinatarios de correo electrónico de clientes y partners siguen configurados y si falla una transmisión de AutoSupport debido a un problema de DNS.

link:https://docs.netapp.com/us-en/ontap/system-admin/manage-autosupport-concept.html["Más información sobre AutoSupport"^].



[[data-protection]]
== Protección de datos

Obtenga más información sobre las funciones comunes de protección de datos compatibles con los sistemas ASA r2.



[[clustered-external-key-servers]]
=== servidores de claves externas agrupados

Puedes configurar la conectividad con servidores de gestión de claves externos en clúster en una máquina virtual de almacenamiento. Con los servidores de claves en clúster, puedes designar servidores de claves primarios y secundarios en una máquina virtual de almacenamiento. Al registrar claves, ONTAP primero intenta con un servidor de claves primario y luego prueba secuencialmente los servidores secundarios hasta que la operación tiene éxito, evitando claves duplicadas.

link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/configure-cluster-key-server-task.html["Aprenda a configurar servidores de claves externas en clúster."^].



[[external-key-management-for-encryption-at-rest]]
=== Gestión externa de claves para el cifrado en reposo

Puede utilizar uno o más servidores KMIP para proteger las claves que el clúster utiliza para acceder a los datos cifrados.

A partir de ONTAP 9.20.1, cuando habilitas un gestor de claves externo en una máquina virtual de almacenamiento de datos, ONTAP migra automáticamente las claves de cifrado de volúmenes de esa máquina virtual de almacenamiento desde el gestor de claves con ámbito de administrador al nuevo gestor de claves de la máquina virtual de almacenamiento de datos. Esto simplifica la transición a la gestión externa de claves y elimina la necesidad de un paso de migración manual independiente en el flujo de trabajo estándar.

* link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/enable-external-key-management-96-later-hw-task.html["Habilitar la gestión de claves externas"^].
* link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/enable-external-key-management-96-later-nve-task.html["Habilitar la administración de claves externas (NVE)"^] .




[[data-security]]
== Seguridad de datos

Obtenga más información sobre las funciones comunes de seguridad de datos compatibles con los sistemas ASA r2.



[[administrator-access-management]]
=== gestión de acceso de administrador

El rol asignado a un administrador determina qué funciones puede realizar. System Manager ofrece roles predefinidos para administradores de clústeres y administradores de VM de almacenamiento. Asignas el rol cuando creas la cuenta del administrador, o puedes asignar un rol diferente más adelante.

link:https://docs.netapp.com/us-en/ontap/task_security_administrator_access.html["Aprenda a gestionar el acceso de administrador con System Manager."^].



[[client-authentication-and-authorization]]
=== Autenticación y autorización del cliente

ONTAP utiliza métodos estándar para asegurar el acceso de clientes y administradores al almacenamiento y para proteger contra virus.  Existen tecnologías avanzadas para el cifrado de datos en reposo y para el almacenamiento WORM.  ONTAP autentica una máquina cliente y un usuario verificando sus identidades con una fuente de confianza.  ONTAP autoriza a un usuario a acceder a un archivo o directorio comparando las credenciales del usuario con los permisos configurados en el archivo o directorio.

link:https://docs.netapp.com/us-en/ontap/concepts/client-access-storage-concept.html["Obtenga más información sobre la autenticación y autorización del cliente"^] .



[[fc-sp-3-authentication-and-encryption]]
=== Autenticación y cifrado FC-SP-3

A partir de ONTAP 9.20.1, ONTAP admite la autenticación y el cifrado del Fibre Channel Security Protocol 3 (FC-SP-3) en HBA seguros de Broadcom con sistemas ASA r2. La compatibilidad con FC-SP-3 permite el cifrado de extremo a extremo a nivel de hardware y la autenticación de dispositivos para proteger los datos en tránsito entre los hosts SAN FC y NVMe/FC y los sistemas de almacenamiento ONTAP, en consonancia con los estándares de seguridad Fibre Channel T11.

* link:https://docs.netapp.com/us-en/ontap/san-admin/fc-sp-3-security-support.html["Más información sobre la autenticación y el cifrado FC-SP-3"^].




[[multi-admin-verification-mav]]
=== Verificación de múltiples administradores (MAV)

A partir de ONTAP 9.20.1, los grupos de aprobación de MAV pueden incluir como aprobadores grupos de proveedores de identidad (IdP), Active Directory (AD) y LDAP (nsswitch), además de administradores individuales. Los tipos de grupos compatibles incluyen Entra ID, ADFS, grupos de dominio de AD y grupos LDAP. Añadir o eliminar usuarios en el directorio de IdP, AD o LDAP no requiere ningún cambio en la configuración de MAV. link:https://docs.netapp.com/us-en/ontap/multi-admin-verify/index.html["Más información sobre MAV"^].



[[oauth-2-0-authentication]]
=== Autenticación OAuth 2.0

Puede utilizar el marco de autorización abierta (OAuth 2.0) para controlar el acceso a sus clústeres ONTAP .  OAuth 2.0 restringe y controla el acceso a los recursos protegidos mediante tokens de acceso firmados.

link:https://docs.netapp.com/us-en/ontap/authentication/overview-oauth2.html["Obtenga más información sobre la autenticación OAuth 2.0"^] .



[[saml-authentication-and-administrator-access]]
=== Autenticación SAML y acceso de administrador

Puede configurar y habilitar la autenticación Security Assertion Markup Language (SAML) para servicios web.  SAML autentica a los usuarios mediante un proveedor de identidad externo (IdP) en lugar de los proveedores de servicios de directorio como Active Directory y LDAP.

link:https://docs.netapp.com/us-en/ontap/system-admin/configure-saml-authentication-task.html["Aprende a configurar la autenticación SAML"^].



[[snmp]]
=== SNMP

A partir de ONTAP 9.20.1, ONTAP admite la autenticación SHA-512 para usuarios de SNMPv3. Esta mejora te permite usar una autenticación SNMPv3 más segura para clientes SNMP externos y para la supervisión de switches, incluidos los que requieren autenticación SHA-512.

* link:https://docs.netapp.com/us-en/ontap/networking/configure_snmpv3_users_in_a_cluster.html["Aprende a configurar usuarios de SNMPv3"^].
* link:https://docs.netapp.com/us-en/ontap-systems-switches/switch-cshm/config-snmpv3.html["Aprende a configurar SNMPv3 en los conmutadores"^].




[[tls-hardware-offload]]
=== Descarga de hardware TLS

Puedes descargar el cifrado y descifrado de Transport Layer Security (TLS) de todo tu clúster a las tarjetas Ethernet compatibles. Esto reduce la sobrecarga de la CPU y mejora el rendimiento de los sistemas que usan TLS.

link:https://docs.netapp.com/us-en/ontap/networking/configure-tls-offload.html["Aprende a configurar la descarga de hardware TLS"^].



[[networking]]
== Redes

Obtenga más información sobre las funciones de red comunes compatibles con los sistemas ASA r2.



[[fips-compliance]]
=== Cumplimiento de FIPS

ONTAP cumple con la norma Federal Information Processing Standards (FIPS) 140-2 para todas las conexiones SSL. Puedes activar y desactivar el modo SSL FIPS, configurar los protocolos SSL de forma global y desactivar cualquier algoritmo de cifrado débil, como RC4 dentro de ONTAP.

A partir de ONTAP 9.18.1, se admiten algoritmos criptográficos de computación post-cuántica para SSL.  Estos algoritmos proporcionan protección adicional contra posibles ataques futuros de computación cuántica y están disponibles cuando el modo SSL FIPS está desactivado.

* link:https://docs.netapp.com/us-en/ontap/networking/configure_network_security_using_federal_information_processing_standards_fips.html["Aprenda a configurar FIPS para todas las conexiones SSL."^].




[[link-aggregation-groups-lags]]
=== Grupos de agregación de enlaces (LAG)

Un grupo de interfaces, también conocido como grupo de agregación de enlaces (LAG), se crea combinando dos o más puertos físicos en el mismo nodo en un único puerto lógico.  El puerto lógico proporciona mayor resiliencia, mayor disponibilidad y reparto de carga.

link:https://docs.netapp.com/us-en/ontap/networking/combine_physical_ports_to_create_interface_groups.html["Aprenda sobre los grupos de agregación de enlaces"^].



[[performance]]
== Rendimiento

Conoce más sobre las funciones de rendimiento comunes compatibles con los sistemas ASA r2.



[[modify-default-settings-that-control-automatic-qos-throughput-ceiling-increases]]
=== Modifica la configuración predeterminada que controla los aumentos automáticos del límite de rendimiento de QoS

Los grupos de políticas de QoS adaptativos y no adaptativos aumentan temporalmente el límite máximo de rendimiento de una carga de trabajo en un 50 % durante 1 segundo de forma predeterminada para responder a demandas a corto plazo de mayor rendimiento. A partir de ONTAP 9.19.1, puedes modificar estos ajustes. En ONTAP 9.18.1 y versiones anteriores, no puedes cambiarlos.

link:https://docs.netapp.com/us-en/ontap/performance-admin/guarantee-throughput-qos-task.html["Obtén más información sobre los techos de rendimiento de QoS"^].



[[ipspace-tcp-performance]]
=== Rendimiento de TCP de IPspace

A partir de ONTAP 9.19.1, ONTAP mejora el rendimiento de la transferencia de datos TCP en enlaces WAN con pérdidas y alta latencia al integrar dos funciones de recuperación de pérdidas, PRR y RACK, en la pila TCP de ONTAP. PRR es adecuado para todas las redes y está activado de forma predeterminada. RACK es adecuado para redes congestionadas con velocidades de enlace de aproximadamente 25 gigabits/segundo y está desactivado de forma predeterminada.

link:https://docs.netapp.com/us-en/ontap/networking/improve-tcp-wan-performance.html["Aprende más sobre cómo mejorar el rendimiento de TCP en WAN con PRR y RACK"^].



[[san-configuration]]
== Configuración de SAN

Una red de área de almacenamiento (SAN) consiste en una solución de almacenamiento conectada a hosts a través de un protocolo de transporte SAN como iSCSI o FC. Puedes configurar tu SAN para que tu solución de almacenamiento se conecte a tus hosts a través de uno o más switches. Si usas iSCSI, también puedes configurar tu SAN para que tu solución de almacenamiento se conecte directamente a tu host sin usar un switch.



[[san-direct-attachment]]
=== Conexión directa SAN

A partir de ONTAP 9.19.1, no es necesario un switch FC para establecer conexiones entre hosts FC y FC-NVMe y el almacenamiento ONTAP. Los hosts se pueden conectar directamente a los puertos del adaptador FC en los sistemas ASA r2. La capacidad de conexión directa puede ser especialmente valiosa en sitios remotos y entornos híbridos en los que la simplicidad es clave.

* link:https://docs.netapp.com/us-en/ontap/san-config/configure-fc-nvme-hosts-ha-pairs-reference.html#direct-attach-fc-and-fc-nvme-configurations["Obtén más información sobre la conexión directa SAN"^].




[[san-protocols]]
== Protocolos SAN

Los sistemas ASA r2 admiten todos los protocolos SAN (iSCSI, FC, NVMe/FC, NVMe/TCP).

* link:https://docs.netapp.com/us-en/ontap/san-admin/san-host-provisioning-concept.html["Obtenga más información sobre el protocolo iSCSI."^].
* link:https://docs.netapp.com/us-en/ontap/san-admin/san-provisioning-fc-concept.html["Obtenga más información sobre el protocolo Fibre Channel (FC)."^].
* link:https://docs.netapp.com/us-en/ontap/concept_nvme_provision_overview.html["Obtén más información sobre el protocolo NVMe."^].
+
** link:https://docs.netapp.com/us-en/ontap/san-admin/nvme-copy-offload.html["Aprenda a configurar la descarga de copia NVMe"^].
+
A partir de ONTAP 9.18.1, ONTAP admite la copia de datos descargados de NVMe. La copia de datos descargados de NVMe permite que un host NVMe descargue las operaciones de copia de su CPU a la CPU del controlador de almacenamiento de ONTAP. El host puede copiar datos de un espacio de nombres NVMe a otro mientras reserva sus recursos de CPU para las cargas de trabajo de las aplicaciones.

** link:https://docs.netapp.com/us-en/ontap/san-admin/enable-space-allocation.html["Obtenga más información sobre la asignación de espacio (desmapeo) para NVMe"^].
+
A partir de ONTAP 9.16.1, la desasignación de espacio (también llamada “perforación de agujeros” y “desmapeo”) está habilitada de forma predeterminada para los espacios de nombres NVMe. La desasignación de espacio permite que un host desasigne bloques no utilizados de los espacios de nombres para recuperar espacio.







[[storage-efficiency]]
== Eficiencia del almacenamiento

La eficiencia del almacenamiento es la medida de la eficacia con la que un sistema de almacenamiento utiliza el espacio disponible optimizando los recursos de almacenamiento, minimizando el espacio desperdiciado y reduciendo la huella física de los datos escritos.

ONTAP proporciona varias tecnologías de eficiencia del almacenamiento que pueden ayudarte a optimizar el uso del almacenamiento y reducir costes.

link:https://docs.netapp.com/us-en/ontap/concepts/storage-efficiency-overview.html["Conoce más sobre las tecnologías de eficiencia del almacenamiento de ONTAP"].



[[data-reduction-rate-drr]]
=== Índice de reducción de datos (DRR)

A partir de ONTAP 9.20.1, la tasa de reducción de datos (DRR) de la eficiencia de almacenamiento ofrece una evaluación más precisa del ahorro de espacio que supone la eficiencia de almacenamiento de ONTAP, ya que solo incluye los datos reducibles. En ONTAP 9.19.1 y versiones anteriores, la DRR incluye tanto los datos reducibles como los no reducibles.

link:https://docs.netapp.com/us-en/ontap/concepts/capacity-measurements.html["Más información sobre cómo ONTAP informa del almacenamiento utilizado"^].



[[global-deduplication]]
=== Deduplicación global

A partir de ONTAP 9.19.1, la _deduplicación global_ amplía la link:https://docs.netapp.com/us-en/ontap/concepts/deduplication-concept.html["ahorro de espacio de deduplicación ONTAP existente"^] a nivel de unidad de almacenamiento a toda la zona de disponibilidad de almacenamiento (SAZ). Al eliminar los bloques de datos duplicados en todas las unidades de almacenamiento de la SAZ, puedes mejorar significativamente la eficiencia del almacenamiento y reducir el coste total de propiedad. La deduplicación global no requiere ninguna licencia de función, está habilitada de forma predeterminada, se integra a la perfección con las tecnologías de eficiencia del almacenamiento existentes y funciona de forma transparente con un impacto mínimo en el rendimiento y sin necesidad de configuración administrativa.

[[user-password-expiration-alerts]]
=== Alertas de vencimiento de las contraseñas de los usuarios

A partir de ONTAP 9.20.1, si el rol asociado a una cuenta de usuario está configurado para alertas de caducidad de contraseña, el usuario recibe una alerta de banner en la parte superior de la página de System Manager inmediatamente después de iniciar sesión, начиная 14 días antes de que caduque la contraseña. La alerta se actualiza cada vez que el usuario inicia sesión para mostrar el número de días que quedan hasta que caduque la contraseña. Puedes configurar las alertas de caducidad al añadir o editar un rol de administrador.

link:https://docs.netapp.com/us-en/ontap/authentication/configure-password-expiry-alerts.html["Descubre cómo configurar las alertas de caducidad de contraseñas en System Manager"^].
