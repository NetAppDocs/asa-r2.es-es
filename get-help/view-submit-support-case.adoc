= Envíe y consulte casos de soporte de los sistemas de almacenamiento R2 de ASA
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si tienes algún problema para el que necesites ayuda, utiliza ONTAP System Manager para enviar un caso al soporte técnico o para consultar los casos cerrados o en curso.

Debes ser link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Registrado con Active IQ"^] para ver los casos de soporte de tu sistema ASA r2.

.Pasos
. Para enviar una solicitud de soporte, en System Manager, selecciona *Cluster > Support*; luego selecciona *Ir a NetApp Support*.
. Para consultar un caso enviado anteriormente, en System Manager, selecciona *Cluster > Support*; luego selecciona *View my cases*.
